# Refik Project Focus

This bundled local extension acknowledges completed Refik tasks when their exact local project window is focused. It reads window focus and the single workspace folder URI, and contacts only the installed Refik helper. It does not read file contents, messages, accounts, or model output. Remote, virtual, and multi-folder workspaces do not acknowledge tasks.

Install and remove it through Refik's central editor setup. An editor profile or policy can disable extensions; Refik reports when it is waiting for a live connection.
